# Resume_Candidato

Plataforma que resume informações dos candidatos às eleições de 2026 de Minas Gerais e à Presidência do Brasil.

## Fontes de dados

Os dados exibidos são provenientes de fontes públicas oficiais:

| Fonte | Tipo de dado |
|---|---|
| **TSE** — Tribunal Superior Eleitoral | Cadastro de candidatos, bens declarados, situação de candidatura |
| **Câmara dos Deputados** | Proposições legislativas, votações, mandatos |
| **Senado Federal** | Atividade legislativa, mandatos |

> **Dados coletados em 04/09/2026.** O projeto não realiza atualização em tempo real; os dados refletem o estado das bases públicas na data de coleta.
